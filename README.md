# 🌐 Sovera Everyday Trading

**Top 50 High-Demand Products for Import/Export** across 5 global markets.

## Markets Covered
🇦🇪 Dubai · 🇮🇳 India · 🇨🇦 Canada · 🇺🇸 US · 🇬🇧 UK

## Features
- 50 products with demand vs supply gap analysis
- Star ratings per product
- Filter by market & category
- Sort by demand, gap, or rating
- Trend indicators (Rising / Stable)
- Mobile friendly

## Run Locally
```bash
npm install
npm start
```

## Deploy to Vercel (Free)
1. Push this repo to GitHub
2. Go to vercel.com → New Project → Import your repo
3. Click Deploy — done!

## Deploy to Netlify (Free)
1. Push to GitHub
2. netlify.com → New site → Connect repo → Deploy
